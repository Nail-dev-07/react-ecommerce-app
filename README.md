### Name of the project
React eCommerce Application

### Project description
React eCommerce Application is a frontend web application that allows users to browse products, 
view product details, add products to the cart and review their order before checkout.

### Technologies used

- React
- JavaScript
- React Router
- Context API
- CSS

### Features

- Display all products
- View product details
- Add products to cart
- Change product quantity
- Remove products from cart
- Calculate total cart price

### How to run an application

To run it user needs to install node modules first using terminal command 'npm install'. 
After node modules have been initialized in project folder run a 'npm run dev' command.
